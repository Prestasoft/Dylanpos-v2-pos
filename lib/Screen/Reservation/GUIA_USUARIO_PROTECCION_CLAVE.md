# Guía de Usuario: Protección por Contraseña para Cancelación de Reservaciones

## Introducción

Para proteger las reservaciones contra cancelaciones no autorizadas, el sistema Dylanpos implementa un mecanismo de protección por contraseña. Este documento explica cómo funciona este sistema y cómo utilizarlo correctamente.

## Cómo Funciona

Cuando un usuario intenta cancelar una reservación, el sistema solicitará una contraseña antes de proceder con la cancelación. Este proceso consta de los siguientes pasos:

1. El usuario selecciona una reservación y hace clic en el botón "Cancelar".
2. El sistema muestra un diálogo de confirmación preguntando si realmente desea cancelar la reservación.
3. Si el usuario confirma, el sistema muestra un segundo diálogo solicitando una contraseña.
4. Si la contraseña ingresada es correcta, la reservación se cancela.
5. Si la contraseña ingresada es incorrecta, se muestra un mensaje de error y la reservación no se cancela.

## Preguntas Frecuentes

### ¿Qué hacer si olvidé la contraseña?

La contraseña está configurada en el sistema y no puede ser recuperada por el usuario. Si ha olvidado la contraseña, contacte al administrador del sistema.

### ¿Se puede cambiar la contraseña?

Sí, la contraseña puede ser cambiada, pero requiere una actualización del código fuente del sistema. Para cambiar la contraseña, contacte al desarrollador o administrador del sistema.

### ¿Por qué necesitamos una contraseña para cancelar reservaciones?

La protección por contraseña ayuda a prevenir cancelaciones accidentales o no autorizadas de reservaciones, lo que podría causar inconvenientes para los clientes y pérdidas para el negocio.

## Soporte

Si tiene alguna pregunta o problema relacionado con la funcionalidad de protección por contraseña, contacte al soporte técnico o al administrador del sistema.
